# Свадебное приглашение — SPA

Одностраничное приложение для свадебного приглашения Романа и Анны. Деплой на Vercel.

## Структура проекта

- `index.html` — все секции приглашения
- `styles.css` — стили (Montserrat + Great Vibes)
- `script.js` — календарь, карусели, слайдер пожеланий
- `vercel.json` — конфигурация Vercel

## Секции

1. Hero — THE WEDDING DAY, фото, дата
2. Приглашение — «Мы официально станем семьёй»
3. Календарь — июль 2026, 25-е выделено
4. RSVP — подтверждение до 25.07.26
5. Локация — место проведения
6. Venue — «HIDE», адрес, фото
7. Тайминг — 16:00–23:00
8. Dress Code — палитра, примеры нарядов
9. Пожелания — слайдер, список подарков
10. Контакты — Анна, Роман
11. До скорой встречи — With Love

## Настройка

**Google Form:** замените `YOUR_FORM_ID` во всех кнопках «Подтвердить присутствие» на ID вашей формы.

**Изображения:** замените URL в `src` на свои фото (сейчас используются Unsplash).

**Ссылка «Как добраться»:** укажите ссылку на Яндекс.Карты или Google Maps.

## Деплой на Vercel

```bash
cd figma-spa
vercel
```

Или подключите репозиторий на [vercel.com](https://vercel.com).

## Адаптивность

- **Mobile**: < 768px
- **Tablet**: 768px – 1024px
- **Desktop**: > 1024px
